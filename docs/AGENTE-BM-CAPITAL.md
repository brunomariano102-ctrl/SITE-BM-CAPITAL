# Como trabalhar com o Agente BM Capital

As instruções do agente estão em `AGENTS.md`, na raiz do projeto. O Codex pode aplicá-las às tarefas realizadas neste repositório. Não foi criado um agente separado na interface nem um processo que roda sozinho.

## Usar aqui no Codex

Continue neste projeto e descreva o resultado desejado. Por exemplo:

> Agente BM Capital, inicie a Missão 02: faça a homologação visual e funcional do site atual. Compare com as referências aprovadas, verifique as sete páginas em desktop e mobile e entregue um checklist para teste do WhatsApp em aparelhos reais. Preserve a identidade visual, não publique, não integre CRM e não adicione rastreadores. Corrija problemas técnicos dentro desse escopo e informe o que depende da minha validação.

Esse exemplo é uma sugestão para uso futuro, não uma missão já executada.

Para uma tarefa menor:

> Agente BM Capital, investigue [problema], preserve o visual aprovado, corrija a causa e execute os testes necessários. Entregue um resumo com os resultados.

## Levar para outra tarefa ou checkout

Inclua `AGENTS.md` na raiz do projeto usado pelo Codex, junto do código atual. As instruções acompanham o arquivo; não presuma que este workspace foi enviado ao GitHub. Nenhum commit, push ou publicação foi feito para criar este agente.

## Decisões que continuam com você

Mudanças de identidade e estratégia, publicação, novas integrações e envio de comunicações reais exigem sua autorização. Aprovação visual e análise jurídica não são substituídas por testes automatizados.
